# Тестовое задание для yadro impulse kvadra 4

# Stack
``C++ 23`` ``Cmake >= 4.1`` ``g++ 15`` ``make 4.4.1``

# Build 
```bash
mkdir build
cmake -B build
cd build && make
```

# Run
Находясь в директории ``build``
```bash
./kvadra_4 -p <path_to_dir> -t <time_delay_in_milliseconds>
```
Аргументы не являются обязательными.
По умолчанию выставляется домашняя директория и задержка в 5 минут.

# О решении

``.media_files`` создается в домашней директории.

Система логгирует в стандартный поток вывода о создании новой версии файла и в ``cerr`` о произошедших исключениях.
